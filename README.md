# Лабораторна робота 3

Варіант 2. Проста програма на Python для керування будівлею.

Є датчики температури, вологості та руху. За їх показаннями вмикаються опалення, вентиляція і світло.

- Якщо температура менша за 21 градус, опалення працює.
- Якщо вологість більша за 60%, вентиляція працює.
- Якщо є рух, світло працює.
- В інших випадках відповідний пристрій вимикається.

## Як запустити

Потрібен Python 3. Додаткових бібліотек немає.

```sh
python main.py
```

У програмі є три приклади зі звіту. Щоб перевірити інші значення, їх можна змінити в кінці `main.py`.

Усі класи знаходяться в одному файлі. Показання датчиків задаються вручну.
